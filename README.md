# Task Flow

**Task Flow** est une application simple pour organiser ses tâches et suivre sa progression.

Elle fonctionne entièrement dans le navigateur.  
Aucune inscription n’est nécessaire et aucune donnée n’est envoyée sur internet.

---

## À quoi ça sert ?

Task Flow permet de :

- Créer et organiser des tâches
- Définir des priorités et des dates
- Suivre ce qui est terminé et ce qui reste à faire
- Avoir un petit profil personnel
- Voir un historique de ses actions

C’est un outil personnel de productivité, simple et clair.

---

## Comment ça marche ?

1. Ouvrez le lien de l’application
2. Allez dans **Mon espace** et créez votre profil
3. Allez dans **Mes tâches** pour ajouter des tâches
4. Consultez le **Dashboard** pour voir votre progression
5. Utilisez **Paramètres** seulement si vous voulez modifier votre profil ou tout effacer

---

## Où sont stockées les données ?

Les données (tâches, profil, historique…) sont enregistrées **uniquement dans votre navigateur**.

Cela signifie que :

- Vous retrouvez vos informations si vous revenez avec le **même navigateur** sur le **même appareil**
- Si vous changez de téléphone, d’ordinateur ou de navigateur, vos données ne seront plus là
- Personne d’autre (y compris le créateur de l’application) ne peut voir ce que vous avez saisi

C’est un fonctionnement local, sans compte et sans base de données en ligne.

---

## Fonctionnalités principales

- Création de tâches avec catégorie, priorité, date et moment de la journée
- Liste temporaire avant enregistrement définitif
- Marquage des tâches comme terminées
- Filtres (Toutes, Affaires, Terminées, Prioritaires)
- Statistiques de progression
- Profil avec photo (ou initiales)
- Mode clair et mode sombre
- Fonctionne aussi sur téléphone

## Pour les personnes techniques

- Application **100 % statique** (HTML, CSS, JavaScript)
- Stockage via `localStorage`
- Aucun backend, aucun serveur, aucune base de données
- Responsive
- Compatible avec n’importe quel hébergement de fichiers statiques (GitHub Pages, Netlify, etc.)
